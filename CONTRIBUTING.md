# Contributing

For a scale or tuning correction, include the exact sounding pitches or
intervals and a primary musical reference. Document aliases rather than
duplicating the same scale under different names.

1. Run `node --test tests/*.test.mjs`.
2. Run `node scripts/build.mjs` and `node scripts/serve.mjs`.
3. Check desktop and phone layouts, both languages and handedness options.
4. For changes to pitch logic or rendering, inspect an exported PDF as well.

Use original educational prose. Code contributions are MIT-licensed; original
educational content uses CC BY 4.0. Follow BRANDING.md for the logo and preserve
all third-party font/library notices.
