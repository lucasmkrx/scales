# Roadmap

These are directions for future work, not scheduled commitments or completed features.

## Next priorities

- Add browser-flow regression tests for dialogs, keyboard selection, custom
  inputs, URL precedence, export, and cancellation. The current CI suite focuses
  on model, geometry, audio, PDF structure, and build behavior.
- Run structured usability sessions with players who know TAB but little theory.
  Record tasks, observations, and changes rather than assuming educational impact.
- Broaden browser and device checks, including mobile keyboards and screen readers,
  and address findings from a formal accessibility audit.
- Measure startup, note-generation latency, and larger PDF exports on documented
  hardware before setting or advertising performance targets.

## Possible extensions

- Expand the guided-book collection with genuinely adapted lessons for additional
  configurations; keep full courses distinct from generated reference atlases.
- Add reviewed contextual explanations and chord-tone practice workflows without
  implying that a root/scale label alone determines what fits a backing track.
- Evaluate richer instrument audio against bundle size, offline behavior, and
  sample licensing requirements.

New catalog entries and tunings should include exact intervals or sounding pitches
and a reliable source. See [Contributing](../CONTRIBUTING.md).
