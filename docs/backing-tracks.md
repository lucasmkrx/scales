# YouTube backing tracks

Below the fretboard, choose a style and tempo, then select **Search YouTube**. Tukany opens the results in a new tab. Start a track there and return to Tukany to play along with your diagram.

The search uses the current root, scale, and instrument. For example, A minor pentatonic with Blues and Slow searches for `slow blues guitar backing track in A minor`. For bass, D Dorian with Funk searches for `funk backing track in D Dorian no bass`.

Slow, Medium, and Fast add a tempo hint. Tukany uses the same search as the matching named scale when it recognizes a custom formula's intervals. For other custom formulas, it searches for a drone on the selected root with no style or tempo terms.
