# YouTube backing tracks

Below the fretboard, choose a style and tempo, then select **Search YouTube**. Tukany opens the results in a new tab. Start a track there and return to Tukany to play along with your diagram.

The search uses the current root, scale, and instrument. For example, A minor pentatonic with Blues looks for an A minor blues track. A Dorian with Funk looks for an A Dorian funk track. Bass searches ask for bassless accompaniment, and guitar searches ask for tracks for lead guitar.

Slow, Medium, and Fast add a tempo hint. For a custom formula, Tukany uses a matching scale name when it recognizes the intervals. Other custom formulas use a drone on the selected root.
