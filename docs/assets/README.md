# Documentation media

These assets show the actual Scales interface and generated output.

- `desktop.png`: left-handed, six-string guitar in E standard, C natural minor,
  Both spelling, 21 frets. Captured at a 1000 CSS-pixel viewport, scrolled to the
  instrument summary and fretboard.
- `mobile.png` and `mobile-picker.png`: the same configuration in a 390 × 720
  CSS-pixel viewport, showing the workspace and scale picker sheet.
- `walkthrough.gif`: five actual app captures: the initial map, the scale chooser,
  C minor pentatonic, degree labels, and the PDF configuration panel. It is an
  illustrative sequence of still frames without audio, not an interaction test.
- `pdf-reference.png`: a rendered page from the matching three-page A4 landscape
  guitar reference PDF, including the full neck and nearby positions.

Outer capture controls were cropped out. No interface elements or fretboard notes
were composited or generated. Refresh media when the UI or layout changes.
