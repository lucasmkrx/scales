# Documentation media

These assets show the actual Scales interface and generated output.

- `desktop.png` shows a left-handed, six-string guitar in E standard at a
  1360 × 1065 CSS-pixel viewport. C natural minor spans frets 0–12. The
  instrument has 21 frets and the note labels use both sharps and flats.
- `mobile.png` shows the same setup at 390 × 730 CSS pixels, scrolled to the
  scale settings and fretboard. The diagram shows frets 0–4 so the open strings
  and the whole practice position fit on screen.
- `mobile-picker.png` shows the scale picker opened from that mobile workspace.
- `walkthrough.gif` follows a desktop player searching for pentatonic scales,
  choosing C minor pentatonic, viewing degrees on frets 5–9, and opening PDF
  export. The five frames are screenshots from a local Chromium session.
- `pdf-reference.png` shows a page from the matching three-page A4 landscape
  guitar reference PDF, including the full neck and nearby positions.
